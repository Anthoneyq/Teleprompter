# PrompterPro quick start - review candidate

This copy is for local review. A supported-device list, price, usage license and support/refund terms still need owner approval before commercial release.

1. Extract the entire folder. Keep `index.html`, `app.js` and `vendor/` together.
2. Open `index.html` in your desktop browser. No server, account or internet connection is required by the app files.
3. Paste your script into Editor, then choose **Load Script**. To see how it works first, choose **Try a sample script** on the start screen.
4. Choose **Play**, or tap the script itself to start and stop. Use **-** and **+** at the bottom of the screen to change speed while you read. Settings has the full speed slider. Reset stops playback and returns to the start. Playback also stops at the end and pauses when the page is hidden.
5. Settings include font size, line spacing, mirroring, guide and accent color. **Close** hides the controls; the top-left **Controls** button opens them again.
6. Edits/settings try to save immediately in this browser. **Save here** retries or explicitly replaces a conflicting/unreadable browser save after confirmation. Read the save status: a failure is not a save.
7. **Export backup** downloads a JSON copy of the current editor text and settings, including changes you haven't loaded into the reading view. Verify the file exists in Downloads. A cancelled download is not a backup.
8. **Import backup** accepts a version 1 PrompterPro JSON backup, validates it first and asks before replacing your current editor/settings. Export current work first if you need it. Restored scripts start paused from the top; reading position isn't backed up.

Browser saves aren't cloud sync or durable backups. Clearing browser data, private-mode cleanup, moving the folder, changing browsers or losing the device can remove access. Keep important exports separately. Avoid editing the same document in two tabs; the app blocks silent overwrites if it detects a different save.

Basic Markdown: headings, paragraphs, lists, bold/italic, quotes, code, rules and tables. HTML is literal text. Links are non-clickable text and images appear as descriptions. Use plain apostrophes/characters rather than HTML entities when writing scripts. The app limits scripts to 200,000 characters and backup files to 2 MB. Nested or unusually complex Markdown can still be slow; keep rehearsal scripts simple.

Keyboard shortcuts work when focus is outside the editor, buttons and inputs: Space play/pause; ↑/↓ speed; ←/→ position; Home/End beginning/end; F controls; H/V mirror; R reset; Escape close controls. When a button has focus, use its native keyboard action or click the reading area before shortcuts.

The app does not record audio/video, follow speech, include a hardware remote or use browser-native fullscreen. While playing it asks the browser to keep the screen awake; some browsers (and opening the file directly from a folder in some browsers) do not allow this, so check your device's auto-lock setting before a long read. The controls toggle only changes the app layout. Use the device's normal display/sleep controls for a rehearsal.

Privacy: this app contains no analytics or network fetches for scripts. It uses browser-local storage and files you export. Other people using the same browser profile may see saved scripts. Do not treat browser storage as encrypted storage. Checkout/support services, once chosen, have separate data handling.

Troubleshooting: keep the full extracted folder together, check the status text, export visible work before refreshing, and avoid private browsing for persistence. When reporting a problem include app release, browser/OS, order reference (after purchase) and redacted error wording. Do not send private scripts unless necessary and explicitly agreed.
